## Quando usare Classic vs Mascot

| Contesto | Versione consigliata |
|---|---|
| Pitch deck enterprise, B2B serio | **Classic** |
| Onboarding consumer-friendly, marketing creator | **Mascot** |
| App icon principale | scegline UNA e mantienila |
| Loading state, splash | Mascot rende meglio (espressioni) |
| Documento legale, fattura | Classic / wordmark |
| Sticker, social, community | Mascot |

I due pack condividono **palette, wordmark e tono di voce**. Sono interoperabili: puoi tenere la wordmark Classic e usare il mascot solo per stati emotivi (loading, conferme, errori).
